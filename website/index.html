The problem

What is ClickFix?

A social-engineering technique that tricks users into performing dangerous actions by showing fake CAPTCHAs, browser verifications, updates or error prompts.

?
Core question

Is this webpage manipulating the user into performing a dangerous action?

Anatomy of an attack

How a ClickFix attack works

STEP 01

Lure

A fake CAPTCHA or verification page.

STEP 02

Manipulation

The user copies an encoded command to the clipboard.

STEP 03

Execution

>_

The user runs the command manually, which bypasses filters.

In the browser

Clear, actionable alerts

ClickShield shows real-time, easy-to-understand alerts with clear guidance, so users can take the right action immediately.

High risk: possible ClickFix attack

  • Verification / CAPTCHA pattern detected
  • Suspicious domain or impersonation signal
  • Clipboard-related behavior
  • Execution-oriented instruction detected
  • Multiple signals correlate
Each signal adds to the page’s score. When several line up, the verdict lands in the high-risk band and the warning appears before anything is run. Try it in the risk engine above.

Recommended action

  1. Do not copy, paste or execute instructions from this page.
  2. Navigate directly to the trusted service instead.
  3. Verify the website URL and look for signs of authenticity.
  4. If in doubt, close the page and report it.
