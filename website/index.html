Core Defense Modules

Built from scratch on Chrome Extension Manifest V3.

🔍
Intent-Based Heuristics
Rather than relying solely on blocklists, ClickShield evaluates instructional sequences directed at users.
📋
Clipboard Protection
Monitors both user clicks and programmatic navigator.clipboard.writeText calls containing command syntax.
🛡️
Shadow DOM Overlays
Intervention modals inject inside a closed Shadow DOM, preventing host page CSS from tampering with security alerts.
⚡
Multi-Signal Correlation
Distinguishes between educational programming articles and coercive social engineering attacks.
🔒
100% Local-First
Zero cloud telemetry. Analysis, logs, and allowlists remain entirely inside the local Chrome storage sandbox.
📊
Command Dashboard
Full-tab security analytics suite featuring GSAP gauges, Recharts threat breakdowns, and JSON audit logging.
